# Учебное портфолио

Вариант 9 — личное портфолио.

## Как открыть
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. CSS подключён из `css/style.css`, иллюстрация находится в `images/portfolio.svg`.

В проекте есть семантическая HTML-структура, навигация с внутренними и внешними ссылками, маркированный и нумерованный списки, таблица, карточки, Flexbox/Grid и медиазапросы.
